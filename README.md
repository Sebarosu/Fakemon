# WELCOME TO FAKEMON!
This is a mod for the Gen 1 recompilatipn made by Brianthatboi (https://github.com/bryanthaboi/pokemon-gen1-recomp-project) whose main goal is
to revive all those Pokegods, fan-made creatures, rumors and Creepypastas in a single mod. We got from entries from the Pokémon Factory and the Beta
to well-known and brand new crossover creatures you never thought you'd see in a Pokémon fangame or mod for the og Game Boy Games.

# LIST OF NEW CREATURES:
- Sapusaur: Overgrowth Pokémon. Obtainable by giving Venusaur a Mist Stone.
- Charcolt: Fire Dragon Pokémon. Obtainable by giving Charizard a Mist Stone.
- Rainer: Rainstorm Pokémon. Obtainable by giving Blastoise a Mist Stone.
- Gorochu: Intense Mouse Pokémon. Obtainable by giving Pikachu a Fire Stone.
- Pikablu: Pink Mouse Pokémon. Obtainable in Route 3.
- Azurai: Purple Rabbit Pokémon. Evolution of Pikablu.
- Jaggs: Shark Pokémon. Obtainable in Route 21.
- Yoshi: Dinosaur Pokémon. Obtainable in Viridian Forest.
- Kirby: Stellar Pokémon. Obtainable in Mt. Moon.
- Sonic: Hedgehog Pokémon. Obtainable in Route 24.

# HOW TO ADD THE MOD MANUALLY?
1. Download the contents of this library as a .zip
2. Go to (your username)/AppData/Roaming/pokemon-love2d
3. Go to your mods folder (or create one if you don't have it).
4. Extract the zip file in its own folder in the mods folder.
5. Way to go!
